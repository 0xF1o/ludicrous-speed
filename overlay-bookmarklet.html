Read in place

Select something, click the bookmark, and the overlay opens with that text, already playing. The X in the corner (or Escape) closes it and puts the page back exactly as it was.

On a phone or tablet (no bookmarks bar)
  1. Tap Copy code above.
  2. Bookmark this page in your browser (Share → Add bookmark, or the ★ button).
  3. Open your bookmarks, edit that bookmark, and paste the code as its URL/address.
  4. Rename it to something short, then select text on any page and pick it from your bookmarks.
How this bookmarklet is built

Source: overlay-bookmarklet.js. The code in this page is generated — npm install && npm run build runs build-overlay.mjs, which minifies the source with terser and percent-encodes it into a javascript: URL inside the button above. Edit the source, not the generated code.

It uses a shadow root, so the page’s CSS cannot break the overlay and the overlay’s CSS cannot leak into the page. Speed, size and theme are remembered per site in localStorage.

Prefer a separate tab? bookmarklet.html opens the reader as its own page instead. The overlay lives entirely in the page you are already on — the text never leaves it.
